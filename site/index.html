Cómo leer estos datos

Una diferencia observada, no una recomendación.

«Alta» y «baja» describen la presencia de un Código Nacional entre las dos exportaciones comparadas. La aplicación no interpreta recetas ni ofrece recomendaciones de dispensación, financiación, sustitución, seguridad o tratamiento.
