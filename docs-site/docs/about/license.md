## Data source

The application reorganizes and compares public exports from the Ministerio de
Sanidad's [Nomenclátor de
facturación](https://www.sanidad.gob.es/profesionales/nomenclator.do). Source
authority, retrieval details, and artifact hashes are preserved in generated
snapshot metadata.

## Independence

nomenclator-delta is an independent open-source project. It is not affiliated
with or endorsed by the Ministerio de Sanidad. The official Nomenclátor and
official publications remain authoritative.

The software provides observed source differences, not dispensing,
reimbursement, substitution, prescribing, treatment, or clinical advice.
